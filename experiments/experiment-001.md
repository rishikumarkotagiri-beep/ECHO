# Experiment 001 — Autonomous Goal Formation

## Question
Can ECHO generate and pursue goals from observations, internal drives, memory, and uncertainty rather than receiving a fixed task every cycle?

## Independent variables
- curiosity strength
- novelty
- memory availability
- prediction error

## Measurements
- goals generated
- actions selected
- memories formed
- prediction errors
- reflections
- capability changes
- repeated behavior

## Important limitation
Goal-directed behavior or self-report does not establish subjective consciousness. The experiment measures architecture and behavior.
